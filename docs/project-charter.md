# Project Charter

## Project Name

AI Resume Screening Platform

## Project Vision

Develop an AI-powered recruitment platform that automates resume screening and assists recruiters in identifying qualified candidates efficiently.

## Business Problem

Recruiters manually review hundreds of resumes for every hiring cycle. This process is repetitive, time-consuming, and susceptible to inconsistency.

## Proposed Solution

Build a web application that accepts resumes, extracts relevant information, compares candidates against job descriptions using NLP techniques, and ranks applicants based on relevance.

## Objectives

- Reduce manual resume screening time
- Improve candidate matching accuracy
- Provide explainable ranking decisions
- Build an intuitive recruiter dashboard

## Stakeholders

- Recruiters
- HR Managers
- Hiring Managers
- System Administrator

## Success Criteria

- Resume uploaded successfully
- Candidate information extracted accurately
- Matching score generated
- Results displayed within a few seconds
