# AI Resume Screening Platform

## Overview

An AI powered recruitement platform that analyzes resumes, compares them against job descriptions, and ranks candidates using natural language processing and machine learning.

## Goals

- Upload PDF resumes
- Extract candidate information
- Match resumes against job descriptions
- Rank candidates
- Explain ranking decisions
- Provide recruiter dashboard
